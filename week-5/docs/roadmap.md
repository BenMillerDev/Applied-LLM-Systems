## Roadmap and Planned Features

NailSalonApp's current status is active development with a complete, functional MVP -- the features described elsewhere in this documentation are built and working today. A separate set of features is planned but not yet implemented, and it's worth being explicit about which is which, since asking about a roadmap item should get a different answer than asking about something that already ships.

Planned but not yet built: push notifications for new bookings, which is blocked on setting up an Apple Developer account; SMS booking confirmations, planned via Twilio; automated reminders to clients who are due for a fill; deposit payments through Stripe at the time of booking; support for multiple staff members under a single salon account, rather than the current single-owner model; a before-and-after photo gallery attached to client profiles; and a custom domain for the customer booking page instead of the default Firebase-hosted URL.

None of these seven items exist in the app today. An owner asking about SMS confirmations, deposits, or multi-staff support right now would need to be told those are planned, not available -- there's no partial or beta version of any of them running yet.
